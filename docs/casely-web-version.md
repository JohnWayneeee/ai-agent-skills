# Casely — Hosted Web Product

[Casely](https://casely.digital/) is a hosted AI-powered workflow and QA tool built on top of the same skills published in this repository.

## What It Does

Casely lets teams build, run, and manage AI-assisted workflows through a visual canvas. It is designed for QA, product, and engineering teams who want to automate test case generation, requirement tracing, and review flows without writing infrastructure code.

## How These Skills Relate

The skills in this repository were developed and refined during the construction of Casely. They represent reusable agent behaviors that are useful outside of Casely too — in Claude Code projects, Codex workspaces, and any compatible agent runtime.

If you find yourself using these skills frequently and want a hosted environment with persistent workflows, collaboration, and integrations built in, Casely is the hosted version of that experience.
